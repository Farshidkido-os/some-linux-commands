# Simple-linux-commands

1.اولین مورد مربوط هستش به machine-id که توی سیستم های لینوکسی روی دو مسیر هستن 
مسیر حال حاضر سیستم های امروزی و مسیر های قدیمی برای دیستوری های قدیمی تر 
این کد برای سیستم های لینوکسی مثل یه کد شناسه هستش که توی vm به کار کاربرا میاد 

2.موارد مربوط به تغییرات توی machine-id هستش بعد clone کردن دیسترو که دارید در صورتی که این تغییرات اعمال نشه ممکنه روی تنظیمات شبکه vm موردنظر مشکل به وجود بیاد
